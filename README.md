# 🚁 スカイパイロット 3D

ブラウザで遊べる **3D ドローン・フライトシミュレーター**です。
iPhone / iPad / Mac のブラウザだけで動きます（Three.js を CDN から読み込むだけで、ビルド不要）。

## 遊び方

| 操作 | 内容 |
|---|---|
| 左スティック | 上下＝昇降（スロットル）、左右＝旋回 |
| 右スティック | 上下＝前後、左右＝左右へ |
| 💛 ゴールドのリング | 貫通するとスコア。8秒以内に連続するとコンボ（最大×5） |
| 🔋 バッテリー | 飛行中に減り、着陸すると充電。0% になるとスロットルが制限され強制着陸になります |
| 🏢 建物 | 激突すると跳ね返り、衝突が激しすぎるとクラッシュ |
| ホバー補助 | ON のとき、スティックを離すと自動ホバリング・自動水平（初心者向け） |

### デスクトップ（キーボード）

| キー | 内容 |
|---|---|
| W / S または ↑ / ↓ | 前進 / 後退 |
| A / D または ← / → | 左右へ |
| Q / E | 旋回 |
| Space / Shift | 昇降 |
| C | カメラ切替（チェイス ↔ FPV） |
| R | リセット |
| H | ホバー補助切替 |
| M | サウンド切替 |
| P | ポーズ |

## ローカルで動かす

```bash
cd 3Dflight
python3 -m http.server 8080
```

- **Mac のブラウザ**: http://localhost:8080
- **iPhone / iPad**: Mac と同じ Wi-Fi に接続し、Safari で
  `http://<MacのローカルIP>:8080` を開く
  （Mac の IP は「システム設定 → ネットワーク」で確認。例: `192.168.1.10`）

> 横画面（ランドスケープ）で遊ぶのが最も快適です。

## 実装メモ

- **ファイル構成**: `index.html` 1ファイルに全て（Three.js r160 を importmap + CDN で読み込み）
- **物理**: ニュートン力学の簡易モデル（スラスト・重力・線形/二次ドラッグ・角度スプリング）。ホバーはスロットル約0.4
- **環境**: 低ポリの町（窓の点いたビル約60棟・道路・木・山・雲・ヘリポート）。ビルは AABB で衝突判定
- **パフォーマンス**: シャドウ 1024px ドローン追尾、InstancedMesh の木、フレームレート低下時のピクセル比自動低下
- **音**: WebAudio 合成（プロペラの唸り・衝突・リング通過）
- **HUD**: コンパス / 高度 / 速度 / バッテリー / スコア & コンボ。Safe Area 対応

## 調整したい場合

`index.html` のモジュールスクリプト内：

- `G / MAX_T / DRAG_L / DRAG_Q`：飛行の重い軽い
- `MAX_ANGLE`：最大バンク角
- バッテリー消費：`updateGame` 内の `0.15 + drone.throttle * 1.7`
- リング数：`for(let i=0;i<10;i++)` の `10`
